Overview

GreenSpace Finder is a community-focused WebGIS application that helps Seattle residents locate nearby public parks, trails, and community gardens. Users can explore green spaces from their current location or by dropping a pin, then view rich detail panels showing amenities, walking distances, and accessibility features.

Built as a team of four for GEOG 458 at the University of Washington, the app layers City of Seattle park data, King County neighborhood boundaries, and OpenStreetMap contributor data into a unified interactive map experience.

What You Can Do

  • Find Nearby Parks — search from your current location or drop a pin to discover green spaces within walking distance.
  • See Amenities — view restroom availability, playgrounds, picnic areas, dog-friendly zones, and public transit access.
  • Plan Accessible Trips — filter parks by accessibility features and walking route difficulty to plan inclusive visits.

Tips for Using the Map

  • Click any park on the map to open the detail panel with photos, distances, and amenity list.
  • Use the filter button to show/hide playgrounds, trails, and dog-friendly areas.
  • If you spot an error in a park's data, check the Sources page to learn how to report it.

Tools & Libraries

Mapbox GL JS Turf.js JavaScript HTML / CSS GeoJSON Fetch API

Spatial Analysis

  • Turf.js buffers — compute walkable radius zones around each park.
  • Turf.js nearest — find the closest park to a dropped pin or current location.
  • Turf.js distance — calculate precise walking distances in meters between user and park.
