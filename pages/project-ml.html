Machine Learning

Yelp Rating
Prediction

A multi-class classification pipeline predicting restaurant star ratings from Yelp review text and business attributes — covering the full ML workflow from feature engineering to model evaluation.

Type Classification
Best Accuracy 81.4%
Dataset Yelp Open Dataset
Year 2025

Overview

This project builds a machine learning pipeline to predict Yelp restaurant star ratings (1–5) from a combination of structured business attributes (location, category, price range, review count) and unstructured review text processed via TF-IDF vectorization.

Four classifiers were trained and evaluated — Logistic Regression, Random Forest, Gradient Boosting, and a Multinomial Naive Bayes baseline — using 5-fold stratified cross-validation. The final Random Forest model achieved 81.4% accuracy on a held-out test set, with strong performance on 4- and 5-star classes.

Learning Curve — Random Forest

ML Pipeline

  • Data Cleaning — dropped nulls, normalized review counts, encoded categorical features (cuisine type, price range).
  • Feature Engineering — TF-IDF on review text (top 500 terms), one-hot encoding for business categories, log-transform on review counts.
  • Model Selection — 5-fold stratified cross-validation across four classifiers with grid search hyperparameter tuning.
  • Evaluation — accuracy, macro F1, confusion matrix, and SHAP-style feature importance on the held-out test set (20% split).

Tech Stack

Python scikit-learn Pandas NumPy Matplotlib Seaborn Jupyter

Data Source

  • Yelp Open Dataset — business.json + review.json, filtered to restaurant category, Seattle metro area (~48k reviews).
