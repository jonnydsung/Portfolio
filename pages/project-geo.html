Washington State
Wildfires Map

An interactive web map visualizing wildfire incidents across Washington State from 2008 to 2025, with year filtering, color-coded fire sizes, and a linked incident table.

Overview

This interactive web map displays wildfire incidents across Washington State from 2008 to 2025. Users can explore individual fire locations, view incident details, and filter fires by year using a dynamic slider that updates both the map and a linked data table simultaneously.

The map focuses on all counties and wildfire-prone regions of Washington State, providing both spatial and tabular insights into how wildfire patterns have shifted across nearly two decades.

Map Features

  • Wildfire Points — individual markers representing each fire incident across the state.
  • Color-Coded by Acres Burned — light colors for small fires, dark colors for large fires, giving an immediate sense of scale.
  • Year Filter Slider — dynamically updates both the map markers and the incident table to show only fires from the selected year.
  • Interactive Table — displays incident name, county, acres burned, and year. Clicking a table row highlights the corresponding fire point on the map.
  • Legend — visual guide explaining the color scale for acres burned.
  • Responsive Design — sidebar layout adapts for smaller screens.

Tools Used

JavaScript HTML / CSS GeoJSON Mapbox GL JS

Data Source

  • Wildfire incident data loaded from a local GeoJSON file: /assets/firedata.geojson

GeoJSON Schema

  • IncidentName — name of the wildfire
  • County — county where the fire occurred
  • AcresBurned — total acres burned
  • Year — year of the incident

Examined Geographic Area

The map covers Washington State, USA — all counties and wildfire-prone regions statewide. By focusing on a single state over 17 years, the visualization surfaces both the geographic clustering of fires (concentrated in eastern Washington) and temporal trends in fire frequency and severity.
